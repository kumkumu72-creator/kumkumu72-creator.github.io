Конфиденциальность

Политика обработки данных

Демонстрационная версия сайта: форма не отправляет заявки. Введённые данные не передаются на сервер и не сохраняются сайтом.

Какие данные запрашивает форма

Имя, компания, должность, контактные данные, модель оборудования и описание сервисной задачи.

Цель обработки

В текущей демонстрации поля используются только для проверки заполнения в вашем браузере. Команда MESTARO не получает введённые сведения.

Текущий режим

Отправка формы отключена. Нажатие кнопки «Проверить заполнение» проверяет обязательные поля и показывает результат в браузере.

Если приём заявок будет подключён

До включения сбора данных эта страница будет обновлена: появятся сведения об операторе, контакты, цели, порядок и сроки обработки данных.
